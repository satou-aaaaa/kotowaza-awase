# ことわざあわせ

短冊のことわざは、一部が欠けています。下に出る「意味」を手がかりに、欠けた言葉を入れる言葉あそびです。ことわざを知らなくても、意味と字数のヒントで解けます。だれでも同じ1日5問、練習・とことんは何度でも。

- 遊ぶ: <https://satou-aaaaa.github.io/kotowaza-awase/>
- 欠けた言葉を入れて「こたえる」。ひらがなでも漢字でも（カタカナでも）正解です。まちがえても何度でも入れ直せます。
- ヒントは2段：1回目は最初の字と字数、2回目は4つから選べます。3回まちがえても4つから選べます（行き止まりになりません）。まちがいもヒントもなしで★3つ。
- 正解すると、ことわざ全体・読み・意味と、同じ意味のことわざ（例：猫に小判 ↔ 豚に真珠）が出ます。
- 今日の5問（やさしい2・ふつう2・むずかしい1）と上級（むずかしい3・ヒントなし）はだれでも同じで1日1回。とことん（一度で何問解けるか。まちがえても続き「ここで降りる」まで）・練習（動物・体・数・食べ物と植物・自然と天気・道具とくらし・人と心のなかま別）は何度でも。
- まちがえた・ヒントを使った問題は、次の日から「おさらい」に出ます（間をあけてくり返すと長く覚えていられる：Cepeda ほか 2006）。出会ったことわざは「ことわざ帳」に集まります。実績・カレンダー（7日前まであとから遊べる）もあります。時間制限はありません。
- ことわざ371・問題521（同じことわざで欠ける所がちがうものを含む）。
- 記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を読み込むとき、Google に IP アドレスが届きます。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（ことわざや答えは入りません）。

## ことわざと意味の出どころ

- ことわざは、昔から言い伝えられ、だれのものでもない言葉です。意味は国語辞典（広辞苑・大辞林・明鏡国語辞典など）の説明を、やさしい言葉に言いかえて書きました。人によって受け取り方が分かれるもの（「情けは人のためならず」など）は、辞典の本来の意味にしています（文化庁「[国語に関する世論調査](https://www.bunka.go.jp/seisaku/kokugo_nihongo/kokugo_shisaku/kotoba_shokudo/index.html)」で取り上げられた言葉）。
- 小学校の国語では、3・4年で「長い間使われてきたことわざや慣用句、故事成語などの意味を知り、使うこと」を学びます（[文部科学省 小学校学習指導要領 国語](https://www.mext.go.jp/a_menu/shotou/new-cs/youryou/syo/koku.htm)）。
- まちがいを見つけたら、[感想のフォーム](https://github.com/satou-aaaaa/kotowaza-awase/issues/new?template=feedback.yml)で教えてください。
